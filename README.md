# Шумбрат — Мордовия (версия с GigaChat)

Это полная копия сайта с тем же интерфейсом, страницей паспорта путешественника, изображениями и разделами. Чат «Лисичка» подключён к GigaChat API.

## Переменные окружения Vercel

В настройках проекта Vercel → Settings → Environment Variables добавьте:

- `GIGACHAT_AUTH_KEY` — Authorization Key из проекта GigaChat API в личном кабинете Sber Developers / GigaChat Studio. Это готовый ключ авторизации (обычно строка Base64), а не временный access token.
- `GIGACHAT_SCOPE` — `GIGACHAT_API_PERS` для личного доступа. Для корпоративного доступа используйте scope, выданный вашему проекту.
- `GIGACHAT_MODEL` — необязательно; по умолчанию `GigaChat`. Укажите только модель, доступную вашему проекту.

После добавления переменных выполните Redeploy. Не вставляйте ключ в `index.html`, `api/chat.js`, GitHub или этот архив.

## Развёртывание

Загрузите содержимое папки проекта в новый GitHub-репозиторий и импортируйте репозиторий в Vercel. Vercel автоматически обнаружит `api/chat.js` как serverless function.

## Как работает авторизация

Сервер обменивает `GIGACHAT_AUTH_KEY` на временный OAuth access token и использует его для запросов к `https://api.giga.chat/v1/chat/completions`. Временный токен кэшируется в памяти экземпляра функции; постоянный ключ остаётся только в переменных окружения Vercel.
